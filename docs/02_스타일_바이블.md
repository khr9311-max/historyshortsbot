# 스타일 바이블 — 역사 인과 쇼츠

> 이 문서의 값은 **확정 상수**다. Manim 씬과 자막은 반드시 이 값을 참조한다.
> 개정은 분기 1회 별도 세션에서만.

## 0. 한 줄 컨셉

**"역사 다큐가 아니라 역사 도해."**

감성적 재현이 아니라 **구조를 보여주는 화면**이다.
시청자가 "슬프다"가 아니라 **"아, 그래서 그렇구나"**를 느껴야 한다.

## 1. 색상 상수

| 이름 | HEX | 용도 |
|---|---|---|
| `BG` | `#0E1420` | 배경 (딥 네이비) |
| `INK` | `#E8E4DC` | 기본 텍스트·선 (오프 화이트) |
| `ACCENT` | `#E4483A` | **강조 1색** — 핵심 인과, 결정적 수치 |
| `SUB` | `#F2A73B` | 보조 강조 (앰버) |
| `MUTE` | `#5A6472` | 비활성 요소, 배경 격자 |
| `DIM` | `#8C97A8` | **약화시키되 읽혀야 하는 텍스트** |

**규칙: 한 화면에 `ACCENT`는 한 곳만.** 두 군데 이상 쓰면 시선이 분산되고 즉시 싸구려가 된다.

> **`DIM` 추가 경위 (2026-08-25, 승인 대기)**
> `MUTE`(#5A6472)를 `BG` 위에 올리면 명암비가 약 1.9:1 이다. 선·격자에는 맞지만
> **글자에 쓰면 읽히지 않는다.** EP001 초판은 프랑스 쪽 라벨을 전부 `MUTE` 로
> 써서 정보가 사라져 있었다. 바이블에 "약하지만 읽히는" 색이 없어서 생긴 구멍이라
> `DIM`(명암비 약 6.3:1)을 채웠다. 취향 변경이 아니라 결손 보완이므로 우선 적용했다.
> 다음 개정 세션에서 확정하거나 다른 값으로 바꿔 달라.
>
> **글자에 `MUTE` 를 쓰지 않는다.** 선·격자·비활성 테두리 전용.

## 2. 타이포

| 항목 | 값 |
|---|---|
| 폰트 | Pretendard Bold (대체: Noto Sans KR Bold) |
| 화면 내 라벨 | 화면 폭의 5% |
| 자막 | 화면 폭의 6.5%, 하단 25% 지점 |
| 자막 색 | `INK` / 핵심어만 `ACCENT` |
| 자막 외곽 | 검정 스트로크 3px |
| 줄 수 | 최대 2줄 |

숫자는 항상 **크게, 단독으로.** 문장 안에 묻지 말고 화면을 점유시킨다.

## 3. 도해 컷 (`diagram`) 문법

이 채널의 정체성이다. 아래 5개 패턴 안에서만 만든다.

| 패턴 | 언제 | 움직임 |
|---|---|---|
| **인과 화살표** | 조건 → 결과 사슬 | 좌→우 순차 등장, 화살표는 `ACCENT` |
| **타임라인 바** | 시간 압축·비교 | 좌에서 우로 채워짐, 분기점만 강조 |
| **지도 이동** | 이동·확산·교역 | 저채도 지도 위 `ACCENT` 경로가 그려짐 |
| **수치 그래프** | 급변·격차 | 축 먼저, 그다음 데이터가 자라남 |
| **픽토그램 대비** | 규모·비율 비교 | 단색 실루엣 배열, 차이나는 쪽만 `ACCENT` |

**공통 규칙**
- 배경은 `BG` 단색 + `MUTE` 격자(투명도 8%)
- 선 굵기 3px 고정
- 요소는 **한 번에 하나씩** 등장. 동시 등장 금지
- `run_time` 최소 1.2초. 등장 후 최소 0.8초 정지
- 화면에 동시 존재하는 요소 **최대 5개**

## 4. AI 영상 컷 (`ai_hero` / `ai_still`)

### 프롬프트 고정 블록
```
, cinematic documentary still, deep navy blue tone, low saturation,
single directional light, heavy atmospheric haze, wide establishing shot,
silhouette figures only, no visible faces,
subtle film grain, 9:16 vertical composition, 2K
```

### 네거티브 (고정)
```
text, letters, numbers, signage, logo, watermark,
close-up faces, hands, modern objects, oversaturated,
cartoon, illustration, cluttered
```

### 절대 금지
- **한글·숫자·문자** — AI는 반드시 깨뜨린다. 텍스트가 필요하면 `diagram` 컷으로
- 실존 인물의 특정 가능한 얼굴
- 클로즈업 얼굴·손

### 카메라 무브 3종만
| 무브 | 용도 | 속도 |
|---|---|---|
| `dolly_in` | 기본 (가장 자주) | 5초에 12% 확대 |
| `orbit` | 훅 컷 | 5초에 15도 이내 |
| `crane_up` | 마무리·스케일 | 5초에 12% 이동 |

프롬프트에 `very slow, subtle camera movement` 필수.

## 5. 오디오 3레이어

| 레이어 | 볼륨 | 비고 |
|---|---|---|
| 나레이션 | 0 dB (기준) | 유료 TTS, 음성 1개 영구 고정 |
| 환경음 | -14 dB | 바람·울림·저음 드론 |
| BGM | -20 dB | 멜로디 약한 앰비언트, 나레이션 시 자동 더킹 |

> **이 값은 '나레이션 대비 상대값'이다.** 소스 파일에 그냥 곱하는 값이 아니다.
> EP001 초판은 `volume=0.20` 처럼 곱하기만 했는데, 소스 환경음이 이미 나레이션보다
> 17 dB 작아서 실제로는 -31 dB 까지 내려갔다 — 분위기 레이어가 사실상 없었다.
> `build.py` 는 각 레이어의 통합 라우드니스를 먼저 측정해 고정 게인으로 맞춘다.
> 나레이션 -16 LUFS 기준, 환경음 -30 LUFS, BGM -36 LUFS.
> 최종 마스터는 **-14 LUFS / TP -1.5 dB** (유튜브 기준).

- 훅 구간(0~5초)에 임팩트음 또는 완전한 정적 중 하나 필수
- `diagram` 컷 요소 등장 시 짧은 틱음(-24 dB) — 정보 전달 리듬을 만든다

### TTS 톤
남성 저음, 차분한 분석가. 속도 0.95배. 문장 끝 하강. **음성 변경 절대 금지.**

## 6. 후처리 3종 (모든 컷 공통, 예외 없음)

1. 필름 그레인 `noise=alls=8:allf=t+u`
2. 비네팅 `vignette=PI/5`
3. 먼지 오버레이 `blend=screen`, 투명도 15%
4. 채도 `eq=saturation=0.90`

`diagram` 컷에도 동일 적용한다. 이게 AI 컷과 도해 컷의 이질감을 없애는 유일한 장치다.

## 7. 편집 규칙

- **하드컷만.** 페이드·슬라이드·줌 트랜지션 전면 금지
- 컷 길이 4.5~5.5초, 훅 컷만 2초
- 1번 씬은 무조건 `ai_hero`
- `diagram` 컷을 3개 연속 배치하지 않는다 (도표 피로)
- 마지막 컷은 `diagram` 요약 패턴으로 닫는다

## 8. 서술 규칙

- 단일 원인 설명 금지. 최소 2조건 결합 구조
- 논쟁 사안은 지배학설/소수설 구분 명시
- 지리결정론·문명우열론·민족주의 프레임 금지
- 모든 수치·연도에 출처. `sources.md` 공란이면 발행 금지
- 반사실("만약 ~였다면")은 훅에서만 쓰고 결론에는 쓰지 않는다

## 9. 세이프 에어리어 (2026-08-25 추가)

쇼츠는 하단에 제목·채널·설명이, 우측에 버튼열이 겹쳐 올라온다.
거기에 번인 자막 밴드까지 빼면 도해가 실제로 쓸 수 있는 영역은 아래뿐이다.

| 구분 | 픽셀 (1080×1920) | Manim 좌표 (frame 9×16) |
|---|---|---|
| 도해 영역 | x 60~1020 · y 132~1368 | x ±4.0 · y −3.4~6.9 |
| 자막 밴드 | y 1420~1700 | — |
| 건드리지 말 것 | y 1700 이하 · 우측 하단 | — |

**도해 구성의 세로 중심은 화면 중앙이 아니라 y ≈ +1.75 다.**
`scripts/lib_style.py` 의 `guard()` 가 이 영역을 강제한다. 벗어나면 렌더가 실패한다.
EP001 초판의 `손익분기점 (0)` 라벨은 오른쪽으로 86px 잘려 있었다.
`no_overlap()` 은 요소끼리 포개지는 것을 잡는다.

## 10. 픽토그램 (2026-08-25 추가)

**이모지 금지.** Manim/Pango 는 컬러 이모지(💡⚙️)를 렌더하지 못하고 빈 칸으로 떨어뜨린다.
EP001 초판 S03 의 아이콘 두 개가 그렇게 사라져 있었다.

픽토그램은 `lib_style.py` 의 벡터 함수로만 만든다:
`person` `gear` `bulb` `coal` `doc` `factory` `coin`
필요한 게 없으면 같은 파일에 벡터로 추가한다. 단색 실루엣 원칙을 지킨다.

## 11. 루프 설계 (2026-08-25 추가)

쇼츠는 자동 반복된다. **마지막은 '끝'이 아니라 '이음매'다.**

1. **문장 루프** — 마지막 나레이션이 첫 컷의 훅으로 이어지게 쓴다.
   EP001: "…주인공이 되지는 못했습니다" → "18세기, 기술이 가장 앞섰던 나라는
   영국이 아니었습니다". 반복 재생이 한 문단처럼 읽힌다.
2. **화면 루프** — 마지막 diagram 씬에 `LOOP_TAIL` 을 주면 모든 요소가 `BG` 로
   수렴해 끝 프레임이 순수 배경색이 된다. `build.py` 가 첫 0.35초를 같은 `BG` 에서
   열어 준다. 이음매가 BG→BG 라서 보이지 않는다.
3. **소리 루프** — 시작 0.25초 페이드 인, 끝 0.9초 페이드 아웃.
4. **'다음 편 예고' 카드를 넣지 않는다.** 루프를 끊는 가장 큰 요인이다.
   예고는 고정 댓글·설명란·종료 화면으로 옮긴다.

§7 의 "페이드 전면 금지"는 **컷과 컷 사이** 규칙이다. 루프 이음매의 0.35초 램프는
전환이 아니라 반복 재생의 접합부이므로 예외로 둔다.

`qc.ps1` 이 첫 프레임과 끝 프레임의 평균색 차이를 검사한다 (채널차 12 이하 통과).

## 12. 타이밍 정합 (2026-08-25 추가)

**컷 길이는 손으로 적지 않는다.** `generate_audio_and_subs.py` 가 실제 나레이션을
측정해 `scenes.tsv` · `sub.ass` · `timing.json` 을 함께 생성한다.

- 컷 경계 = 문장 사이의 **정지 구간**. 말 도중에 컷하지 않는다.
- Manim 씬은 `DURATION` 을 선언하고, 초과하면 렌더가 실패한다.
- `build.py` 는 모든 컷을 정확한 프레임 수로 맞춘다 (모자라면 마지막 프레임 유지).

EP001 초판은 컷을 자르기만 하고 늘리지 않아 1.2초가 밀렸고, 자막이 어긋나고
마지막 문장 0.76초가 잘려 나갔다.
