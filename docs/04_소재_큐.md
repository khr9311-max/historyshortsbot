# 소재 큐 — 역사 인과 쇼츠

> 큐는 항상 20개 이상 유지. 소재 선정 기준은 하나다:
> **"결과는 다들 아는데, 왜 그렇게 됐는지는 대부분 모르는 것."**

각 소재에 `도해 패턴`을 미리 지정해두면 제작이 빨라진다.

## 발행 우선순위

**파일럿 3편은 A그룹에서.** 인과가 명확하고, 도해 패턴이 단순하고, 정치적 논쟁 소지가 가장 낮다.

**C그룹은 채널이 자리잡은 뒤에.** 지리결정론 프레임으로 미끄러지면 역사 커뮤니티에서 바로 지적당하고, 그 한 번으로 채널 신뢰가 통째로 날아간다.

**근현대 민족 갈등 소재는 초기 6개월 회피.** 조회수는 잘 나오지만 댓글창이 무너지고 채널 정체성이 그쪽으로 고착된다.

## 큐 관리

- 사용한 소재는 `사용완료`로 이동, 조회수·시청지속률 기록
- 같은 그룹 3편 연속 금지
- 도해 패턴도 3편 연속 같은 것 쓰지 않는다
- 큐가 10개 미만이면 즉시 발굴 세션
